# 下書き記法

紙の譜面を手早く書き起こすための、1小節1行のテキスト形式です。
編集画面の「下書きの取り込み」で、このファイル（`.draft.txt`）をそのまま読み込めます。
1パートの曲だけを扱います（複数パートの曲は `.koto.json` で取り込みます）。

`npm run draft` を実行すると、このフォルダの `.draft.txt` を `.koto.json` に変換し、検算結果を行番号つきで表示します。

## 全体の形

```
title: 六段の調
composer: 八橋検校 作曲
beats: 4
perSystem: 4
---
[段 初段]
五'ヒ ○ 三 ~壱 ; テー ン トン シャン
○ %三_'2 %三_'3 八_. 七__ &六_ 七_'オ ; _ シャ シャ コー ロ リ チイ
```

- `---` より上が見出し、下が小節です。
- `#` から行末まではコメントです。空行は無視されます。

## 見出し

| 項目 | 内容 |
|---|---|
| `title` `subtitle` `composer` | 曲名、副題、作曲者 |
| `meter` | 拍子表示（例：`4/4`） |
| `beats` | 1小節の拍数（既定） |
| `perSystem` `perPage` | 1段の小節数、1ページの段数 |
| `tuning` | 調弦表の1行。左右は `|` で分ける。複数行は項目をくり返す |
| `note` | 譜面に載せる注記 |
| `pitches` | 絃 壱〜巾 の音高を13個（例：`D4 G3 A3 …`） |

## 小節の行

`音符 音符 … ; 口唱歌 口唱歌 …`

### 音符

`[つなぎ][前記号] 絃 [音価線][付点][右肩記号][上記号][波線]` をこの順に、空白を入れずに書きます。

| 書き方 | 意味 |
|---|---|
| `壱` 〜 `巾` | 絃（壱弐三四五六七八九十斗為巾） |
| `○` | 休符 |
| `●` | 拍の中に置く付点。前の音を、この付点自身の長さだけ延ばす。`五 ●_ ●__ 四__` は「四分の五、八分の付点、十六分の付点、十六分の四」 |
| `ワ` `ス` | 記号音符（輪連、すくい爪） |
| `壱+五` | 合せ爪（上から順に）。囲みなしで重ねる |
| `(壱+五` | 合せ爪に左の弧を付ける |
| `△九` `▲九` `▲▲九` | 押し手（一重＝半音、二重＝一音、三重＝一音半） |
| `~壱` `%壱` | かき爪、わり爪 |
| `八_` `八__` `八___` | 音価線1本（八分）、2本（十六分）、3本（三十二分） |
| `八_.` | 音符のすぐ後ろに付く付点（同じ拍の中で完結するもの） |
| `五'ヒ` `壱'3` | 右肩記号（1字ずつ `'` を付ける。`七'オ'ハ` のように重ねられる） |
| `十"左` `六"F` | 上記号（`"F` はフェルマータ、`"甲` は甲音の点） |
| `巾<サ` … `六>ラ` | 波線の始点と終点（文字は省略可。小節をまたいでよい） |
| `&六_` | 音価線を前の音符と必ずつなぐ |
| `!六_` | 音価線を前の音符と必ず切る |

音価線は、何も書かなければ同じ拍の中だけ自動でつながります。拍をまたいでつながる箇所に `&` を、拍の中で切れる箇所に `!` を付けます。

### 口唱歌

- 空白で区切った字を、音符に順に対応させます。`_` はその音符を飛ばします。
- `ロ@7/4` のように書くと、音符と関係なくその拍位置に置きます。

## 小節に掛かる指定

小節の行の**前**に、`[ ]` で書きます。

| 書き方 | 意味 |
|---|---|
| `[段 初段]` `[段 四段 少速]` | 段名（2つ目以降は添え書き） |
| `[速 徐 @2]` | 速度指示（`@` は小節内の拍位置） |
| `[文 三半音上る]` | 文字指示 |
| `[拍 2]` | この小節だけ拍数を変える（弱起など） |
| `[自由]` | この小節は拍数を検算しない |
| `[複]` `[終]` | 右の小節線を複縦線、終止線にする |
| `[反復始]` `[反復終]` | 反復記号 |
| `[改段]` `[改頁]` | この小節の後で改段、改ページ |
| `[段組 8]` | この小節から1段の小節数を変える |

代替譜だけは、小節の行の**後**に書きます。

```
○ 七 八_. 七__ &六_ 七_'オ ; _ ツン コー ロ リ チイ
[或は @2: 八_ 七_]
```

## この記法で書けないもの

取り込んだあと、編集画面で追加します。

- 補助行（歌詞、歌の節、他楽器の手）
- 破線・押し手括弧・1番2番括弧
- 複数パート
